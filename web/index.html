如何获取 DLsite Cookie？（点击查看分步说明）
  1. 在 Chrome / Edge 等浏览器中登录 DLsite，并打开你的收藏夹页面。
  2. 按 F12 打开开发者工具，切换到「网络 / Network」标签。
  3. 按 F5 刷新页面，在请求列表中点击任意一个 dlsite.com 请求。
  4. 在右侧「标头 / Headers」→「请求标头 / Request Headers」中找到 Cookie:。
  5. 复制 Cookie: 后面的完整值（不要包含“Cookie:”本身），粘贴到上方输入框，再点击「保存设置」。
Cookie 相当于登录凭据，请勿发给他人或截图公开。
